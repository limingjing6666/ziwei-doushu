# 第一版主星断语库的可重复提取

来源：[紫微斗数开源解读数据集 v4.0](https://github.com/Renhuai123/ziwei-doushu/releases/tag/v4.0-13d)，作者王多鱼AI，[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)。本库经过提取、删句、去重与频率排序，不是上游私有断语库。倪海厦《天纪》引文不在授权范围，本脚本不保留这类标记句与所附引语。古籍公版引文可保留。

## 重建

只需 Python 3 + zstandard，不添加 npm 依赖。直接流式读取 `.zst`，无需解压到磁盘；允许 128MiB 长窗口（兼容 `zstd --long=27`）。原始压缩包约 10MB，流式处理约 3.7GB JSONL；不要下载/解压全部年份。

```bash
python3 -m venv scripts/build-star-db/.venv
scripts/build-star-db/.venv/bin/pip install -r scripts/build-star-db/requirements.txt
mkdir -p scripts/build-star-db/data
for y in 1950 1963 1977 1990 2004; do
  curl -fLsS "https://github.com/Renhuai123/ziwei-doushu/releases/download/v4.0-13d/year-$y.jsonl.zst" \
    -o "scripts/build-star-db/data/year-$y.jsonl.zst"
done
# 建议先下载 Release 的 SHA256SUMS.txt，核验这五个文件。
scripts/build-star-db/.venv/bin/python scripts/build-star-db/build.py \
  scripts/build-star-db/data/year-*.jsonl.zst
```

默认写入 `lib/ziwei/star-db.generated.ts` 与本目录 `stats.json`；可用 `--output` / `--stats` 改路径。输入按文件名排序；频率相同按文本排序，不含随机数或时间戳。改用更多年份不会改变格式；56 个必需组合任一缺失，脚本以非零状态退出。

本次运行使用已下载样本 `/tmp/ds/y1990.zst`（即官方 `year-1990.jsonl.zst`）与另外四年。完整五文件 SHA-256 见 `stats.json`，均已与官方 SHA256SUMS 核对；正常下载名重跑时仅统计中的文件名有所不同，TS 内容不变。连续重建 TS 的 SHA-256 已验证一致。

## 分组与代表性选择

1. JSONL 每行一张盘，`c` 是 13 维 Markdown；`ms` **仅是命宫第一主星**，不能拿它给夫妻/财帛/官禄分组。
2. 各维度按正文 `本宫主星：...` 取该宫的实际主星集合；固定十四星顺序作为键。正文若写“空宫，借对宫”，使用 `空宫借:星1+星2`，**不得误归本宫坐星**。空宫借星参考必须配合当前盘的对宫验证。
3. 只提取 `一句话定调` 和 `核心论断`，到下一结构标题/关键推导为止，不使用带真实大限等信息的整篇解读。
4. 每个“宫位维度 × 单星/精确组合”内规范空白、计数去重。定调取最高频 1 条，核心取最高频 1–2 条，合计最多 3 条；排除互相包含的近重复段。**单星内容只由真实单星宫取得，不从双星文本拆配。**
5. 现有 SEO 字段与 markers 保持兼容，主星单星可生成全部 182 个知识页。组合、借星条目供 RAG 使用，不额外生成错误的 SEO slug。

## 引文与风险过滤

- `天纪 / 倪师 / 倪海厦 / 倪先生 / B站 / bilibili / BV号 / 第N集(讲) / pNN / 时间码 / 同集` 为受限标记。
- 所有过滤共用带引号/括号栈的完整句切分（包括风险/四化过滤），不在引文内部的标点处分句；**有标记的句子整句丢弃**，连同引号内容，不仅删署名。关联的“他也讲 / 他又说 / 上述 / 这句话”等续句也保守删掉，避免留下孤立的逐字引用。原始段落引号/括号不配对则整段舍弃；无受限标记的公版古籍引文可保留。
- 另外删去断死、灾祸、离婚、残疾、侮辱性断词等句子，以及数据集本盘的四化、当前大限叠加句，避免套错用户命盘。旧亮度条件可保留为参考，模型必须以当前盘亮度为准。
- 这是可审计的启发式，不是自动版权法律判定；商用前建议继续人工抽检。AI 检索层还会过滤既有 `patterns.ts` / `heming-knowledge.ts` 内容，不传 `ni_quote` 或原始合盘长篇引语。

## 本次覆盖与过滤统计

- 1950、1963、1977、1990、2004，共 **43,824** 张盘。
- **50** 个星组键：14 单星 + 24 双星 + 12 空宫借星组；共 **650** 个星组 × 主题组合。
- 四个核心宫位共 **200** 个精确组 × 宫位组合，包含 **56/56** 个十四主星 × 命宫/夫妻/财帛/官禄必需组合；额外覆盖福德、迁移、疾厄、田宅等主题。
- 受限标记涉及 **225** 个去重段落；实际丢弃 **228** 种去重句单元、**388,144** 句次（在原始重复记录中计数）。句单元保护引号里的标点后计数，故不等于朴素按句号统计的数量。
- 另删 **147,506** 句次的恐吓/本盘四化等风险或叠加内容，丢弃 **3,460** 次原始引号/括号不配对段落。未选取的其他章节不进入库，不包含在这个删句数内。
- 产物约 **430KiB**，不是原始全文。精确统计见 [`stats.json`](./stats.json)。
