# 传统紫微：主题方法工具箱

本目录不模拟人物，不附带授权、传承或背书主张。提炼对象是判断思想，不是讲课表达。材料截止 2026-10-31。

## 流程与可审计产物

1. 从外部只读 clone 读取五个指定 book，以原始 JSONL 的一基行号生成 `e0001` 一类稳定 ID。文件整体 SHA-256 见 `extraction-manifest.json`；原文件没有自带 id，因此不伪造上游编号。
2. 先依 book / h2 / h3 排序。短主题在同 book 内相邻合并，长主题切分，保留主题字段；共 1,129 条、21 包，每包 42–60 条。没有使用其他 book。剔除相法、住宅等专门主题；混合条目里仍有无关内容，抽取指令要求忽略，复核时继续剔除。
3. `scripts/distill-method.py` 使用官方模型 `deepseek-flash`，并发 2，候选只写 `/tmp`。完整成功批次用量 175,529 tokens（输入 153,486，输出 22,043）。先前一次因输出上限失败，未保留完整 usage，不声称此数字覆盖失败费用。未把源文、候选全文或密钥放进仓库。
4. 模型候选有灾祸、疾病、性别刻板推断、绝对婚期及规则误读，均不能直接发布。人工回看最终引用的原条目后，重新组织为 30 条方法规则；5 个核心模型、7 步流程、5 项风格维度及 4 类诚实边界另行合成。安全边界是本站政策，不冒称来自教材。
5. `rules.json` 的 claim 独立表述，condition 用结构字段列出索引与触发条件；polarity 仅为阅读方向，不是吉凶评分；source_ids 只存 ID。`source-index.json` 保存 book、主题哈希、视频 part 与证据哈希，无原句。

## 核心模型与三重验证

参考 [nuwa-skill extraction framework](https://github.com/alchaincyf/nuwa-skill/blob/main/references/extraction-framework.md)（MIT），以主题 Skill 而非人物 Skill 的方式使用其框架。没有复制框架的示例句，也不保留个人口癖。

| 模型 | 复现证据 | 生成性应用 | 区分与限制 |
|---|---|---|---|
| 关联而非孤点 | structure、palace、ziwei-help，跨主题及讲次 | 新问题先取关系范围，而非翻单星断语 | 保留三合结构，不把任意宫位拼在一起 |
| 背景约束短期 | decade、life-time、opportunity，跨讲次 | 年度与阶段冲突先交代背景 | 不把某年压力放大到终身 |
| 符号随情境翻译 | palace、ke-meaning、quan，跨主题/讲次 | 同一符号按领域与人生阶段换译 | 不预设职业头衔与个人身份 |
| 组合必须核条件 | brightness、mixed、pattern-first、juri | 格局名称不足以代替亮度与位置核查 | 支持和制约并列，拒绝贴标签 |
| 反馈与选择优先 | context、validate，跨讲次 | 将解读转成待核对问题 | 不宣称科学验证，不将环境当神秘因果 |

这里的“生成性”“区分性”是编辑层面的评估，不是模型对未见命盘的实证成绩。这些框架并非某个人独有；个别观察只降为启发式，不包装成专属思想。

### 置信与公版交叉

- 18 条 high：去重后，至少两个 h2 主题或两个视频 part 有证据。
- 12 条 low：单处或同讲次证据。尤其固定四化、小年度简化法、换日和闰月等不提升为通用真理。部分多 ID 其实同一原句的跨分类重复，按 evidence_hash 去重，不因此提置信。
- `ziwei-help` 与《紫微斗数全书》紫微星论的辅佐思想重合，单独标出。只标方法层面的重合，不声称逐字校勘、版本确定或得到古籍实证支持。其他规则未完成独立版本核对，保持 null，不制造验证结果。
- 固定本命标记的观点与本站可选飞化补充有流派张力：保持分层而非混用。午夜换日和闰月有口径差异：记录低置信，不改已有排盘算法。
- 原仓库若干“古籍原文”段实际含现代整理痕迹，不能只因目录名就豁免逐字检查；本站扫描不设古籍目录白名单。出版版本和现代释义的进一步人工校订仍需完成。

## 接入

`framework.ts` 注入系统提示；`retrieve.ts` 提供星、宫、格局和四化索引，按同宫、三合或相夹关系复核条件。专门规则每盘最多 6 条，另保留结构与大限两条主线。解释规则不是判定现实事件。双盘各自检索并标 A/B，总参考上限仍为 6000 字。

## 诚实边界

不推算死亡或灾祸，不预测医疗结局、不替代专业意见、不按星曜污名化人。低置信只作核对线索；缺少所选运限与年份时必须说明。风格采用结论先行、依据可复查、日常化与短段落；不继承原材料的绝对断言或个人身份。
